### 📌 Sobre a Atividade

Nesta etapa do projeto **Desafio Pit Wall (GP de São Paulo)**, desenvolvemos uma **landing page temática de Fórmula 1** utilizando **HTML5** e **CSS3**. A página apresenta informações sobre o circuito de Interlagos, grid de pilotos com identidade visual, tabela de classificação do campeonato com filtros visuais e um formulário interativo para reserva de ingressos e envio de mensagens aos pilotos.

### 🛠️ Ferramentas Utilizadas

| Ferramenta | Aplicação no Projeto |
| :--- | :--- |
| **HTML5** | Estruturação semântica da página . |
| **CSS3** | Estilização  da página em modo Dark, variáveis de cores (`:root`),e efeitos de transição. |
| **CSS Grid & Flexbox** | Alinhamento responsivo do cabeçalho, cards de pilotos, seções e colunas do formulário. |
| **Google Fonts** | Tipografia personalizada utilizando a fonte `Titillium Web` para estética. |
| **Visual Studio Code** | Ambiente de Desenvolvimento Integrado (IDE) utilizado na codificação do projeto. |

---

### 📂 Conteúdo do Portfólio

| Seção / Componente | Recursos e Conteúdo |
| :--- | :--- |
| **Cabeçalho e Hero (`topbar` & `hero`)** | Menu de navegação fixo, banner principal com faixa diagonal vermelha, imagem de fundo e dados da pista (voltas, quilometragem e curvas). |
| **Grid de Pilotos (`#pilotos`)** | Cards responsivos com numeração estilizada e cores personalizadas por equipe (Ferrari, McLaren, Mercedes e Audi). |
| **Classificação (`#classificacao`)** | Barra de filtros visuais (busca por piloto e seleção de equipe) e tabela completa com destaque para o líder e indicadores de escuderia. |
| **Ingressos (`#ingressos`)** | Painel informativo com aviso de disponibilidade, lista de valores por setor e formulário completo de reserva com upload de foto e recado. |
